Step 2 — Connect and Test Each API Individually
-----------------------------------------------
Before combining:

Use sandbox mode or test keys from Amadeus, Duffel, and Expedia to fetch realistic but non-live data.

Start by calling endpoints like:

Amadeus → /v2/shopping/flight-offers

Expedia → /lodging/availability

ExchangeRate.host → /convert?from=USD&to=CAD

Store results (JSON) in local files or temporary DB tables for debugging.​

Check that all results contain price, currency, and availability fields — these will be essential for the optimizer.

Step 3 — Normalize and Combine Data
--------------------------------------
Implement a preprocessing script (e.g., in Python or Node.js):

Convert all prices to a single base currency using ExchangeRate.host.

Extract relevant fields (e.g., flight → airline, route, total cost; hotel → name, rating, price).

Build a data model like:

json
{
  "flight": { "carrier": "Thai Airways", "price": 760 },
  "hotel": { "name": "Riverside Stay", "price": 360 },
  "transit": 40,
  "buffer": 20,
  "currency": "CAD"
}
This structured format will then be fed to the optimizer.

Step 5 — Add Real-Time Validation
---------------------------------
Once the optimizer decides a “winner,” rerun price verification APIs:

Use Amadeus Flight Offers Price Revalidation API (/v2/shopping/flight-offers/pricing).

For Expedia, call the Rate Checks endpoint before booking.

Re-fetch ExchangeRate.host to ensure up-to-date conversion.

This step guarantees accuracy and prevents outdated pricing at checkout.​
